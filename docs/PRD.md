---

## 1. 프로젝트 개요

### 목적

물리적 마커(20mm 노란색 원형 마커)를 활용하여 관절의 움직임, 거리, 각도를 정량적으로 측정하는 웹 기반 분석 도구 개발.

### 타겟 유저

- 물리치료사
- 재활 연구자
- 운동 기능 평가가 필요한 임상 사용자
- 홈 재활 모니터링 사용자

### 핵심 가치

고가의 모션캡처 장비 없이 스마트폰/노트북 카메라와 저가형 마커만으로 임상적 활용이 가능한 정량 데이터를 제공.

---

## 2. 시스템 범위 및 제한 사항

### 2.1 MVP 범위

초기 버전(MVP)은 다음 조건을 전제로 한다.

- 단안(monocular) RGB 카메라 기반
- 2D 평면 움직임 분석 중심
- 카메라 고정 환경 권장
- 관절 움직임은 카메라와 가능한 평행한 평면에서 수행
- 실시간 분석 및 CSV 저장 지원

### 2.2 제한 사항

다음 상황에서는 측정 오차가 증가할 수 있다.

- 카메라 흔들림
- 마커 가림(Occlusion)
- 조명 변화
- 마커 기울어짐
- 3차원(out-of-plane) 움직임: **카메라 기울기 5° 당 약 0.4% 거리 오차 발생**
- 광각 렌즈 왜곡
- 마커 경계 흐림

MVP 단계에서는 절대적인 3D 위치 추정보다 2D 영상 평면 내 거리 및 각도 분석을 우선 목표로 한다.

### 2.3 최소 지원 환경

| 항목 | 최소 사양 |
|---|---|
| 브라우저 | Chrome 90+, Safari 15+, Firefox 90+ |
| 카메라 해상도 | 720p 이상 |
| CPU | 모바일: Apple A12 / Snapdragon 730 급 이상 |
| 메모리 | 3GB 이상 |

> WebAssembly(WASM) 기반 OpenCV.js는 저사양 기기에서 20 FPS를 보장하지 못할 수 있다. 기기 성능에 따라 FPS가 저하될 경우 UI에 경고를 표시하고 프레임 스킵 모드로 전환한다.

## 3. 개인정보 및 데이터 처리 방침

### 3.1 설계 원칙: 로컬 전용 처리

이 앱은 다음 원칙을 따른다.

- **서버 전송 없음**: 모든 영상 처리 및 데이터 분석은 사용자 기기의 브라우저 내에서만 수행된다.
- **환자 식별 정보 미수집**: 앱은 이름, 생년월일, 진단명 등 개인 식별 정보를 저장하거나 요구하지 않는다.
- **세션 데이터 로컬 저장**: 측정 결과는 브라우저 IndexedDB에만 저장되며 외부로 전송되지 않는다.
- **영상 미저장**: 카메라 스트림은 실시간 분석에만 사용되며, 영상 원본은 저장되지 않는다.

### 3.2 임상 사용 시 주의사항

물리치료사 등 의료 전문가가 환자 측정에 사용할 경우:

- 이 앱에서 내보낸 CSV는 환자 식별 정보를 포함하지 않으므로, 환자 기록과의 연결은 사용자 책임으로 외부에서 관리한다.
- 이 앱은 진단 도구가 아닌 **참고용 측정 보조 도구**로 포지셔닝한다. 의료기기 소프트웨어(SaMD) 규제 적용을 받지 않는 범위로 설계한다.
- 향후 진단 보조 목적으로 기능이 확장될 경우 식약처 SaMD 가이드라인 검토가 필요하다.

### 3.3 저장소 구조

| 저장 대상 | 저장소 | 보존 기간 |
|---|---|---|
| 측정 세션 데이터 | IndexedDB | 사용자 삭제 시까지 |
| 캘리브레이션 설정 | LocalStorage | 사용자 삭제 시까지 |
| 영상 원본 | 저장 안 함 | — |

> LocalStorage는 캘리브레이션 설정 등 소용량 설정값에만 사용한다. 프레임 데이터 등 대용량은 IndexedDB에 저장하여 5MB 용량 한계를 회피한다.

## 4. 마커 사양 (Marker Specification)

### 4.1 기본 사양

- 형태: 원형
- 직경: 20mm
- 색상: 고채도 노란색
- 표면: 무광 권장
- 배경 대비 확보 필요

### 4.2 권장 사항

**초기 프로토타입**

- 노란색 폼폼 마커 사용 가능

**정밀 분석 단계**

- 평평한 원형 스티커 권장
- 또는 ArUco / AprilTag 확장 고려

### 4.3 검출 품질 기준

앱은 다음 품질 지표를 계산한다.

- 원형도(Circularity)
- 검출 면적
- 경계 선명도
- 신뢰도(Confidence Score)

기준 이하일 경우 사용자에게 재설정 안내 표시.

## 5. 주요 기능 (Key Features)

### 5.1 실시간 마커 트래킹

**색상 기반 검출**

HSV 색 공간 기반 노란색 마커 검출.

**중심점 계산**

Contour 기반 centroid 계산 및 sub-pixel refinement 적용.

**지름 추출**

`minEnclosingCircle()` 기반 마커 지름(px) 계산.

**mm/px 변환계수 계산**

실제 마커 지름(20mm)과 영상 내 지름(px)을 비교하여 프레임별 mm/px 변환계수 계산.

MVP 단계에서는 절대적인 Z-depth 추정이 아니라 영상 평면 내 거리 보정을 우선 목표로 한다.

**다중 마커 관리**

- 최대 8개 마커 동시 추적 지원
- 마커 라벨링 지원 (기본값: M1~M8)
- 사용자 수동 지정 가능 (아래 5.2 참조)
- 위치 기반 추적 유지

---

### 5.2 마커 할당 UX

마커 할당은 **초기 검출 단계**와 **측정 설정 단계**로 나뉜다.

#### 초기 검출 단계

1. 앱이 화면에서 노란색 마커를 자동 검출하여 임시 ID(M1, M2, ...)를 부여한다.
2. 검출된 마커는 영상 오버레이에 번호와 함께 강조 표시된다.
3. 마커가 자동 검출되지 않으면 사용자가 **영상 위를 직접 클릭/탭**하여 수동으로 마커 위치를 지정할 수 있다.

#### 마커 이름 지정

- 오버레이에서 마커 라벨을 클릭하면 인라인 편집 모드가 활성화된다.
- 사용자는 라벨을 신체 부위명으로 변경할 수 있다 (예: `shoulder`, `elbow`, `wrist`).
- 라벨은 CSV 컬럼명으로 그대로 사용된다.

#### 각도 계산 설정 (관절 각도 정의)

- 사용자는 **3개의 마커를 순서대로 선택**하여 하나의 각도 계산 그룹을 정의한다.
  - 첫 번째 선택: 근위부 마커 (예: `shoulder`)
  - 두 번째 선택: **정점(Apex) 마커** — 각도가 계산되는 관절 (예: `elbow`)
  - 세 번째 선택: 원위부 마커 (예: `wrist`)
- 정의된 그룹은 이름을 붙여 저장할 수 있다 (예: `elbow_flexion`).
- 여러 각도 그룹을 동시에 정의하여 다중 관절을 병렬 측정할 수 있다.
- 그룹은 편집/삭제 가능하며, 다음 세션에서 재사용할 수 있도록 LocalStorage에 저장된다.

#### 마커 ID 재매핑

- 마커가 일시적으로 화면을 벗어났다가 돌아올 경우, 앱은 **마지막으로 알려진 위치와의 거리**를 기반으로 동일 마커에 같은 ID를 재할당한다.
- 재매핑 실패 시(거리 임계값 초과), 오버레이에 경고를 표시하고 사용자에게 수동 재지정을 요청한다.

---

### 5.3 관절 각도 분석

**각도 계산**

5.2에서 정의된 그룹을 기반으로 `atan2()` 벡터 각도 계산.

**제공 지표**

- 실시간 각도
- 최대 각도
- 최소 각도
- ROM (Range of Motion)
- 평균 각속도
- 각속도(Angular Velocity)

---

### 5.4 거리 및 움직임 분석

**거리 계산**

- 두 마커 간 거리
- 이동 경로 길이(Path Length)
- 총 이동 거리

**궤적 분석**

- 2D trajectory visualization
- 속도 변화 분석

---

### 5.5 데이터 안정화 및 보정

**필터링**

- Moving Average
- Kalman Filter
- Savitzky-Golay Filter (향후 고려)

**노이즈 감소**

- Jitter suppression
- Outlier rejection

**누락 프레임 처리**

마커가 일시적으로 사라질 경우:

- Linear interpolation
- Last-known position 유지

## 8. 사용자 시나리오 (User Flow)

**Step 1. 마커 부착**

사용자가 분석 대상 부위에 마커 부착.

**Step 2. 카메라 세팅**

- 카메라 선택 (전면/후면/외부 웹캠)
- 삼각대 또는 고정 거치 권장
- 카메라 평면 정렬

**Step 3. 캘리브레이션**

- HSV 자동 조정
- 마커 검출 품질 확인
- mm/px 기준 확보

**Step 4. 마커 할당 및 각도 그룹 설정**

- 자동 검출된 마커 라벨 확인 및 필요 시 수정
- 각도를 측정할 관절별로 3개 마커 순서 지정 (근위 → 정점 → 원위)
- 설정 완료 후 미리보기로 각도 계산 확인

**Step 5. 측정 구간 지정 및 측정 시작**

- [측정 시작] 버튼을 눌러 측정 구간을 시작한다.
- 실시간 각도 및 거리 오버레이 표시.
- [측정 종료] 버튼을 눌러 구간을 종료한다.
- 한 세션 내에서 여러 구간을 반복 측정할 수 있다. 각 구간은 개별 라벨로 저장된다 (예: `rep_1`, `rep_2`).

**Step 6. 결과 분석**

그래프 및 CSV 다운로드 제공.
